การเปลี่ยนฟอนต์ (Font) ใน Notepad++ สามารถทำได้ง่ายๆ โดยเข้าไปที่เมนูการตั้งค่าตามขั้นตอนด้านล่างนี้ครับ:

ขั้นตอนการเปลี่ยนฟอนต์
ไปที่แถบเมนูด้านบน เลือก Settings (การตั้งค่า) -> Style Configurator... (ตัวกำหนดลักษณะ...)

ดูที่ช่องด้านซ้าย:

ในช่อง Language เลือกเป็น Global Styles

ในช่อง Style เลือกเป็น Default Style

ดูที่กรอบ Font Style ด้านขวา:

Font name: คลิกเลือกฟอนต์ที่คุณต้องการ (เช่น Consolas, Courier New, Tahoma หรือฟอนต์ภาษาไทยที่คุณชอบ)

Size: เลือกขนาดตัวอักษรตามต้องการ

สิ่งสำคัญที่สุด: ให้ติ๊กถูก [✓] ที่ช่อง Enable global font และ Enable global font size ด้วย (เพื่อให้ฟอนต์นี้มีผลกับทุกภาษาและทุกไฟล์ที่เปิด)

คลิกปุ่ม Save & Close เป็นอันเรียบร้อยครับ

💡 คำแนะนำเพิ่มเติม: สำหรับการเขียนโค้ดหรือดูข้อความทั่วไป แนะนำให้ใช้ฟอนต์ประเภท Monospace (เช่น Consolas, Fira Code, JetBrains Mono) เพราะตัวอักษรและเว้นวรรคจะมีขนาดเท่ากันเป๊ะๆ ทำให้จัดบรรทัดง่ายและอ่านสบายตาครับ
