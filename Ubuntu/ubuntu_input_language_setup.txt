Ubuntu Input Language Setup
setxkbmap -layout "us,th" -option "grp:win_space_toggle" &
setxkbmap -layout "us,th" -option "grp:alt_shift_toggle" &
setxkbmap -layout "us,th" -option "grp:grave_toggle" &

ในการใช้งาน Openbox บน Linux การสลับภาษา (Input Method) มักไม่ได้ถูกกำหนดโดยตัว Window Manager (Openbox) โดยตรง แต่จะขึ้นอยู่กับ Keyboard Layout Handler ที่คุณเลือกใช้ นี่คือวิธีการตั้งค่าและคีย์ลัดที่นิยมใช้ครับ:

1. ตั้งค่าผ่านคีย์บอร์ดโดยตรง (XKB)
หากคุณไม่ได้ใช้โปรแกรมช่วยจัดการตัวอื่น คุณสามารถใช้คำสั่ง setxkbmap เพื่อกำหนดคีย์สลับภาษา (เช่น Alt+Shift หรือ Caps Lock) ได้โดยใส่คำสั่งในไฟล์ ~/.config/openbox/autostart

ตัวอย่างคำสั่งสลับด้วย Alt+Shift:
Bash
setxkbmap -layout "us,th" -option "grp:alt_shift_toggle" &
ตัวอย่างคำสั่งสลับด้วยปุ่ม Grave Accent (ปุ่มตัวหนอน ~):
Bash
setxkbmap -layout "us,th" -option "grp:grave_toggle" &
2. ใช้โปรแกรมจัดการ Input Method (แนะนำ)
สำหรับ Openbox ซึ่งไม่มี Panel บอกสถานะภาษาในตัว การใช้โปรแกรมเสริมจะช่วยให้สลับภาษาได้ง่ายและเสถียรกว่า:

IBus (Intelligent Input Bus)
เป็นที่นิยมมากที่สุดสำหรับภาษาไทย:

ติดตั้ง: sudo apt install ibus ibus-gtk ibus-thai

เพิ่มคำสั่ง ibus-daemon -drx ในไฟล์ autostart ของ Openbox

ตั้งค่าผ่านคำสั่ง ibus-setup เพื่อเลือกคีย์ลัด (เช่น Super+Space หรือคีย์ที่ต้องการ)

Fcitx / Fcitx5
ยืดหยุ่นและทำงานได้ดีกับแอปพลิเคชันหลายประเภท:

ติดตั้ง: sudo apt install fcitx5 fcitx5-thai

เพิ่มคำสั่ง fcitx5 -d ในไฟล์ autostart

ตั้งค่าคีย์ลัดผ่าน fcitx5-config-qt

3. สรุปคีย์ลัดมาตรฐานที่มักใช้กัน
หากคุณติดตั้งระบบเหล่านี้แล้ว คีย์เริ่มต้นมักจะเป็นอย่างใดอย่างหนึ่งดังนี้:

โปรแกรม / ระบบ	คีย์ลัดมาตรฐาน
XKB (System Default)	Alt + Shift หรือ Ctrl + Shift
IBus	Super (Windows key) + Space
Fcitx	Ctrl + Space
ปุ่มตัวหนอน (เฉพาะไทย)	Grave Accent (ต้องตั้งค่าเพิ่มเอง)
วิธีแก้ไขไฟล์ Autostart ของ Openbox
เพื่อให้คีย์ลัดทำงานทุกครั้งที่เปิดเครื่อง ให้แก้ไขไฟล์ดังนี้:

เปิด Terminal

พิมพ์ nano ~/.config/openbox/autostart

เพิ่มบรรทัดคำสั่งที่เลือกไว้ (เช่น setxkbmap...) ลงไปที่ท้ายไฟล์

บันทึกและ Restart Openbox หรือ Log out แล้วเข้าใหม่ครับ
