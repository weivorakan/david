How to config at startup (similar to .bashrc) - Num Lock Case

การปิด Auto Num Lock ใน Xubuntu 24.04 (ซึ่งใช้ Desktop Environment เป็น XFCE) สามารถทำได้ง่ายๆ ผ่านเมนูการตั้งค่าครับ โดยปกติจะมี 2 จุดหลักที่ต้องเช็ก คือตอนที่คุณล็อกอินเข้ามาแล้ว กับตอนที่อยู่ที่หน้าจอ Login (LightDM)

1. ปิดในหน้า Settings (หลังล็อกอิน)
วิธีนี้จะผลต่อการใช้งานหลังจากที่คุณเข้าสู่ระบบเรียบร้อยแล้ว:
- ไปที่ Settings Manager (ตัวจัดการการตั้งค่า)
- เลือกหัวข้อ Keyboard (แป้นพิมพ์)
- ไปที่แท็บ Restore num lock state on startup (คืนค่าสถานะ num lock เมื่อเริ่มระบบ)
- ให้ ยกเลิกการติ๊กถูก (Uncheck) หรือเลือกปิดการใช้งานในส่วนนี้

2. ปิดในหน้า Login Screen (LightDM)
หากเครื่องของคุณเปิด Num Lock ตั้งแต่หน้าถามรหัสผ่าน และคุณต้องการให้มันปิดถาวร ต้องไปแก้ที่ไฟล์คอนฟิกของ LightDM ครับ:
- เปิด Terminal (Ctrl+Alt+T)
- พิมพ์คำสั่งเพื่อแก้ไขไฟล์คอนฟิก (ต้องใช้สิทธิ์ sudo):
	sudo mousepad /etc/lightdm/lightdm.conf
	(ถ้าไฟล์ว่างเปล่า ให้ลองเช็กที่ /usr/share/lightdm/lightdm.conf.d/ แทน)
- มองหาบรรทัดที่เขียนว่า greeter-setup-script หรือเพิ่มบรรทัดนี้ลงไปในส่วนของ
```
[Seat:*]:
greeter-setup-script=/usr/bin/numlockx off
```
- บันทึกไฟล์ และลอง Restart เครื่องดูครับ
หมายเหตุ: หากคุณยังไม่มีโปรแกรม numlockx สามารถติดตั้งได้ด้วยคำสั่ง sudo apt install numlockx ก่อนครับ

3. ตรวจสอบใน BIOS/UEFI
บางครั้ง Hardware จะเป็นตัวสั่งเปิด Num Lock เองตั้งแต่ตอนบูตเครื่อง:
- ขณะเปิดเครื่อง ให้กดปุ่ม (เช่น F2, F12, หรือ Del) เพื่อเข้า BIOS/UEFI
- มองหาเมนู Boot Settings หรือ Advanced Settings
- หาหัวข้อ NumLock State แล้วปรับเป็น Off หรือ Disabled


*****คำถาม*****
ของเครื่องผมมีสองไฟล์ ชื่อว่า lightdm-gtk-greeter.conf กับ users.conf คืออันแรกใช่หรือไม่ และผมสังเกตว่ามีปิดด้วย '#' แปลว่าอันนี้คล้ายๆกับ ~/.bash_profile เป็นการเซ็ทค่าเริ่มต้นตั้งแต่ตอน login มาใช่หรือไม่
***************

เข้าใจถูกต้องเลยครับ! คุณมาถูกทางแล้วครับ ทั้งเรื่องไฟล์และสัญลักษณ์ #
1. ไฟล์ไหนคือตัวจริง?
ใน Xubuntu/XFCE ไฟล์ที่คุมหน้าตาและพฤติกรรมของหน้า Login (Greeter) คือ lightdm-gtk-greeter.conf ครับ ส่วน users.conf มักจะใช้สำหรับตั้งค่าเกี่ยวกับรายชื่อผู้ใช้ที่โชว์บนหน้าจอ (เช่น ซ่อนชื่อ user บางคน)

ดังนั้น ให้จัดการที่ lightdm-gtk-greeter.conf ได้เลยครับ

2. สัญลักษณ์ # (Comment) คืออะไร?
แม่นยำมากครับ มันทำงานเหมือนกับ .bash_profile หรือไฟล์ Config อื่นๆ ในระบบ Linux:

เมื่อมี # นำหน้า: ระบบจะมองข้ามบรรทัดนั้นไป (ถือเป็นคำอธิบาย หรือ "Commented out") ทำให้ระบบกลับไปใช้ "ค่าเริ่มต้นจากโรงงาน" (Default) แทน
เมื่อลบ # ออก: เป็นการเปิดใช้งานคำสั่งนั้น (Uncomment) เพื่อบังคับใช้ค่าที่เรากำหนดเอง

3. วิธีแก้ที่ถูกต้องในไฟล์ lightdm-gtk-greeter.conf
ให้คุณเปิดไฟล์ด้วยสิทธิ์ sudo แล้วมองหาบรรทัดที่มีคำว่า indicators หรือ set-numlock:
- เปิดไฟล์: sudo mousepad /etc/lightdm/lightdm-gtk-greeter.conf
- มองหาบรรทัด: #set-numlock=true
- แก้ให้เป็น: set-numlock=false (อย่าลืมลบ # ข้างหน้าออกด้วยนะครับ)
- Save และ Restart

💡 ความแตกต่างระหว่างไฟล์นี้กับ .bash_profile
lightdm-gtk-greeter.conf (System-wide): มีผลตั้งแต่ ก่อนคุณพิมพ์รหัสผ่าน (หน้าจอมืดๆ ที่มีช่องให้ใส่ Username/Password) มันเป็นระดับระบบปฏิบัติการ

.bash_profile หรือ XFCE Settings (User-specific): มีผล หลังจากคุณ Login เข้าไปแล้ว เป็นการตั้งค่าส่วนตัวของคุณเอง

สรุป: ถ้าคุณอยากให้ไฟ Num Lock ดับตั้งแต่ตอนจะพิมพ์รหัสผ่าน ให้แก้ที่ไฟล์ lightdm-gtk-greeter.conf ตามนี้ได้เลยครับ!


*****คำถาม*****
ผมตรวจดูใน BIOS Settings แล้ว ไม่พบหัวข้อ NumLock state แต่มาพบปัญหาตั้งแต่เริ่มใช้ Xubuntu โดยเฉพาะเมื่อใช้ mini keyboard เสริม ผมลองพยายามทำด้วยการกำหนดด้วย set-numlock=false แล้ว แต่ก็ไม่ได้ผล แต่ด้านบนจะมี blancket ที่เขียนว่า [greeter] นะครับ ถูกต้องใช่หรือไม่ ไม่ได้เขียนว่า [Seat:*]: นะครับ
***************

ถูกต้องแล้วครับ สำหรับไฟล์ lightdm-gtk-greeter.conf หัวข้อหลักจะเป็น [greeter] ครับ ส่วน [Seat:*] นั้นปกติจะอยู่ในไฟล์ lightdm.conf (ตัวหลัก) ดังนั้นคุณแก้ถูกไฟล์และถูกตำแหน่งแล้วครับ

แต่ถ้าแก้ในไฟล์นั้นแล้วยังไม่ได้ผล (ซึ่งเกิดขึ้นได้บ่อยกับพวก Mini Keyboard ที่มีวงจรควบคุมภายใน) แสดงว่ามี "ตัวสั่งเปิด" จากที่อื่นที่ทำงานซ้อนทับอยู่ เรามาลอง "ไม้ตาย" อื่นๆ ที่มักจะได้ผลกับ Xubuntu 24.04 กันครับ:

1. ใช้คำสั่งปิดผ่าน "Settings Editor" (Xfconf)
บางครั้งค่าใน GUI Settings ปกติอาจจะไม่ทำงาน ให้ลองสั่งปิดผ่านฐานข้อมูลการตั้งค่าของ XFCE โดยตรง:
- เปิด Terminal
- พิมพ์คำสั่งนี้แล้วกด Enter:
	xfconf-query -c xfce4-keyboard-layout -p /Default/Numlock -n -t bool -s false
	(คำสั่งนี้เป็นการบังคับให้สถานะเริ่มต้นของ NumLock ในโปรไฟล์ผู้ใช้เป็น false)

2. แก้ไขที่ไฟล์คอนฟิกหลักของ LightDM (สร้างขึ้นใหม่)
ในเมื่อใน [greeter] ไม่ได้ผล เราจะไปสั่งที่ตัวควบคุมระบบ Login (Seat) แทนครับ:
- สร้างไฟล์คอนฟิกใหม่ (เพื่อไม่ให้ไปยุ่งกับไฟล์เดิมของระบบ):
	sudo mousepad /etc/lightdm/lightdm.conf.d/99-disable-numlock.conf
- ถ้าโปรแกรมถามรหัสผ่านให้ใส่ให้เรียบร้อย จากนั้นคัดลอกข้อความนี้ไปวาง:
	[Seat:*]
	greeter-setup-script=/usr/bin/numlockx off
- Save และปิดโปรแกรม

3. ตรวจสอบว่ามี numlockx หรือยัง?
วิธีในข้อ 2 จำเป็นต้องมีโปรแกรมตัวเล็กๆ ที่ชื่อ numlockx เป็นตัวช่วยสั่งปิดครับ:
- ใน Terminal พิมพ์: sudo apt update && sudo apt install numlockx
- เมื่อติดตั้งเสร็จ ลองพิมพ์คำสั่ง numlockx off สดๆ ใน Terminal ดูว่าไฟที่คีย์บอร์ดดับลงไหม

ทำไม Mini Keyboard ถึงมีปัญหา?
Mini Keyboard หลายรุ่นถูกออกแบบมาให้ "บังคับเปิด" NumLock ทันทีที่ได้รับไฟเลี้ยง เพราะมันไม่มีแผงตัวเลขแยก (Numpad) มันจึงต้องเปิดเพื่อให้ปุ่มตัวอักษรบางปุ่มกลายเป็นตัวเลขแทน หากวิธีข้างต้นยังไม่ได้ผล อาจเป็นไปได้ว่า Firmware ของคีย์บอร์ดตัวนั้นส่งสัญญาณเปิดซ้ำหลังจากที่ Linux บูตเสร็จแล้วครับ

สรุปสิ่งที่ควรเช็กอีกครั้ง:
- ในไฟล์ lightdm-gtk-greeter.conf บรรทัด set-numlock=false ต้อง ไม่มี เครื่องหมาย # อยู่ข้างหน้าสุด
- ลองถอด Mini Keyboard ออกแล้ว Reboot ดูว่าคีย์บอร์ดหลักของเครื่องยังมีอาการเดิมไหม เพื่อเช็กว่าเป็นที่ Software หรือที่ตัว Hardware เสริมครับ
