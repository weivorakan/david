การใช้งาน Terminal ใน Ubuntu (Linux) ให้คล่องแคล่ว เริ่มต้นจากคำสั่งกลุ่ม Navigation (การนำทาง) และ File Management (การจัดการไฟล์) ครับ

นี่คือสรุปคำสั่งพื้นฐานที่จำเป็นต้องรู้:

1. การนำทางและจัดการ Directory (Navigation)
คำสั่งกลุ่มนี้ใช้สำหรับ "เดิน" ไปตามโฟลเดอร์ต่างๆ และดูว่าเราอยู่ที่ไหน

pwd (Print Working Directory): ใช้ดูว่าตอนนี้เราอยู่ที่ตำแหน่งโฟลเดอร์ไหน

ls (List): ใช้แสดงรายชื่อไฟล์และโฟลเดอร์ในตำแหน่งปัจจุบัน

ls -l: แสดงรายละเอียดไฟล์ (ขนาด, สิทธิ์การเข้าถึง, วันที่แก้ไข)

ls -a: แสดงไฟล์ที่ถูกซ่อนไว้ (ไฟล์ที่ขึ้นต้นด้วยจุด .)

cd (Change Directory): ใช้สำหรับเปลี่ยนโฟลเดอร์

cd Documents: เข้าไปยังโฟลเดอร์ Documents

cd ..: ย้อนกลับออกไป 1 ชั้น

cd ~: กลับไปยัง Home directory ของเราทันที

cd /: ไปยัง Root directory (จุดเริ่มต้นของระบบ)

2. การจัดการไฟล์และโฟลเดอร์ (File & Folder Management)
เมื่อเข้าไปยังตำแหน่งที่ต้องการแล้ว คุณสามารถจัดการสิ่งต่างๆ ได้ด้วยคำสั่งเหล่านี้:

mkdir [ชื่อโฟลเดอร์] (Make Directory): สร้างโฟลเดอร์ใหม่

touch [ชื่อไฟล์]: สร้างไฟล์เปล่าขึ้นมาใหม่

cp [ต้นทาง] [ปลายทาง] (Copy): คัดลอกไฟล์

cp -r [โฟลเดอร์ต้นทาง] [ปลายทาง]: คัดลอกโฟลเดอร์ (ต้องใส่ -r)

mv [ต้นทาง] [ปลายทาง] (Move): ใช้สำหรับ "ย้าย" หรือ "เปลี่ยนชื่อ" ไฟล์/โฟลเดอร์

rm [ชื่อไฟล์] (Remove): ลบไฟล์ (ระวัง: ลบแล้วกู้คืนยากมาก)

rm -r [ชื่อโฟลเดอร์]: ลบโฟลเดอร์พร้อมไฟล์ข้างในทั้งหมด

cat [ชื่อไฟล์]: แสดงเนื้อหาในไฟล์ออกมาบนหน้าจอ

3. คำสั่งเกี่ยวกับการจัดการระบบและสิทธิ์ (System & Permissions)
ใน Ubuntu บางคำสั่งต้องการสิทธิ์ผู้ดูแลระบบ (Admin)

sudo (SuperUser DO): ใส่ไว้หน้าคำสั่งอื่นเพื่อรันในฐานะ Admin (ระบบจะถามรหัสผ่าน)

clear: ล้างหน้าจอ Terminal ให้สะอาด

history: ดูประวัติคำสั่งที่เราเคยพิมพ์ไปก่อนหน้า

man [ชื่อคำสั่ง]: ย่อมาจาก Manual ใช้สำหรับดูวิธีใช้งานคำสั่งนั้นๆ อย่างละเอียด

💡 ทริคเล็กๆ สำหรับมือใหม่:
ปุ่ม Tab: พิมพ์ชื่อไฟล์หรือโฟลเดอร์แค่ไม่กี่ตัวแล้วกด Tab ระบบจะเติมคำที่เหลือให้โดยอัตโนมัติ (ช่วยให้ทำงานเร็วขึ้นและไม่พิมพ์ผิด)

ปุ่มลูกศร ขึ้น/ลง: ใช้เพื่อเลื่อนดูคำสั่งเก่าๆ ที่เคยพิมพ์ไปแล้ว


1. สลับหน้าจอไปที่ Terminal (TTY)
ถ้าหน้าต่างกราฟิกค้างหรือคลิกไม่ได้ ให้กดปุ่ม:
Ctrl + Alt + F1 (หรือ F2 ถึง F6)
เครื่องจะสลับจากหน้าจอ Openbox กลับมาที่หน้าจอดำ (Prompt) เพื่อให้คุณพิมพ์คำสั่งได้ครับ

2. คำสั่ง Reboot ใน Ubuntu
เมื่ออยู่ที่หน้าจอดำแล้ว ให้พิมพ์คำสั่งใดคำสั่งหนึ่งด้านล่างนี้ครับ:

คำสั่งมาตรฐาน:

Bash
sudo reboot
คำสั่งแบบบังคับทันที:

Bash
sudo shutdown -r now
(ระบบจะถามรหัสผ่านของคุณ ให้พิมพ์ลงไป แม้จะมองไม่เห็นตัวอักษรขณะพิมพ์ก็ไม่ต้องตกใจครับ พิมพ์เสร็จแล้วกด Enter ได้เลย)

3. วิธี "ปิดเฉพาะ Openbox" (ไม่ต้องรีบูตทั้งเครื่อง)
ถ้าคุณไม่อยากรีบูตเครื่องใหม่ทั้งหมด แต่อยากแค่ฆ่าโปรแกรมกราฟิกทิ้งเพื่อเริ่ม startx ใหม่ ให้ใช้คำสั่งนี้ที่หน้า TTY ครับ:

Bash
sudo pkill -u [ชื่อ user ของคุณ]
หรือถ้าจะปิด X Server โดยตรง:

Bash
sudo systemctl restart display-manager
(แต่สำหรับกรณีของคุณที่ลงแบบ Server เพียวๆ การใช้ sudo reboot จะเป็นการล้างค่าที่ค้างอยู่ได้สะอาดที่สุดครับ)

4. กรณี "เครื่องค้างสนิท" (Magic SysRq)
ถ้ากด Ctrl + Alt + F1 แล้วยังนิ่ง ไม่มีการตอบสนอง ให้ใช้ท่าไม้ตายสุดท้ายของ Linux (The Nuclear Option) ครับ:

กดปุ่ม Alt + PrtSc (Print Screen) ค้างไว้

ในขณะที่ค้างไว้ ให้กดปุ่มเหล่านี้ทีละตัวตามลำดับ: R E I S U B
(จำง่ายๆ คือ "RE-I-SUB" หรือคำผวนของ "BUSIER")

เครื่องจะทำการปิดโปรแกรมและ Reboot ตัวเองทันทีอย่างปลอดภัยครับ
