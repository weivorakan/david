Instruction of installing in Ubuntu Server

**Exported:** 5/5/2026 16:51:55  
**Link:** [https://gemini.google.com/app](https://gemini.google.com/app)

## Prompt:
ใช้คำสั่งอะไรบน Terminal ของ Ubuntu server 26.04 LTS เพื่อลง openbox

## Response:
สำหรับการติดตั้ง **Openbox** ซึ่งเป็น Window Manager ที่เบาหวิวและปรับแต่งได้สูงบน **Ubuntu Server 26.04 LTS** (เวอร์ชันล่าสุดของปี 2026 เลยนะครับ!) คุณสามารถทำได้ง่ายๆ ผ่าน Terminal ดังนี้ครับ

### 1\. อัปเดตรายการแพ็กเกจ
ก่อนอื่นต้องทำให้แน่ใจว่าดึงข้อมูลเวอร์ชันล่าสุดมาจาก Repository ของ Ubuntu:
sudo apt update

### 2\. ติดตั้ง Openbox และส่วนประกอบที่จำเป็น
เนื่องจาก Ubuntu Server มักจะไม่มีระบบกราฟิก (X Window System) มาให้ เราจึงต้องลงตัวขับเคลื่อนหน้าจอไปด้วยครับ:
sudo apt install openbox xorg xterm
*   **openbox**: ตัวจัดการหน้าต่างหลัก
*   **xorg**: Display Server ที่ทำให้หน้าจอแสดงผลกราฟิกได้
*   **xterm**: Terminal emulator พื้นฐาน (เผื่อไว้พิมพ์คำสั่งตอนเปิดเข้า GUI ครั้งแรก)

### 3\. การเข้าสู่ระบบ GUI (เลือกได้ 2 วิธี)
#### **วิธีที่ A: ใช้คำสั่ง startx (แบบ Manual)**
ถ้าคุณไม่อยากให้เครื่องโหลดหน้าจอ Login อัตโนมัติ ให้ติดตั้งเครื่องมือนี้เพิ่ม:
sudo apt install xinit
จากนั้นพิมพ์ `startx` เพื่อเข้าหน้าจอ Openbox ครับ

#### **วิธีที่ B: ติดตั้ง Display Manager (แบบมีหน้าจอ Login)**
ถ้าอยากให้เปิดเครื่องมาแล้วมีช่องให้พิมพ์ Username/Password สวยๆ แนะนำ **LightDM** ซึ่งเบาและเข้ากับ Openbox ได้ดี:
sudo apt install lightdm lightdm-gtk-greeter
หลังจากติดตั้งเสร็จและ Reboot เครื่อง ระบบจะพาคุณเข้าสู่หน้า Login โดยอัตโนมัติ

### 4\. เครื่องมือเสริมที่ควรมี (Recommended)
Openbox ตัวเปล่าๆ จะมาพร้อมกับหน้าจอว่างเปล่า (คลิกขวาเพื่อเปิดเมนู) เพื่อให้ใช้งานง่ายขึ้น ผมแนะนำให้ลงเครื่องมือเหล่านี้เพิ่มครับ:
*   **obconf**: สำหรับตั้งค่า Themes และ Appearance ของ Openbox
*   **menu**: เพื่อให้ Openbox สร้างรายการโปรแกรมในเมนูคลิกขวาให้อัตโนมัติ
*   **tint2**: สำหรับคนต้องการ "แถบ Taskbar" ด้านล่าง

**คำสั่งติดตั้งรวดเดียว:**
sudo apt install obconf menu tint2

* * *

### สรุปขั้นตอนสั้นๆ
ถ้าคุณต้องการแค่ตัวแอปหลักเพื่อรันเลย ให้ใช้คำสั่งเดียวจบ:
> `sudo apt update && sudo apt install openbox xorg xinit`
**เกร็ดเล็กน้อย:** ใน Ubuntu 26.04 การจัดการความปลอดภัยและ Snap อาจจะเข้มงวดขึ้น แต่สำหรับ Openbox ที่เน้นความ Minimalist การใช้ `apt` ยังคงเป็นวิธีมาตรฐานที่เสถียรที่สุดครับ


## Prompt:
ผมมีเรื่องแปลกอีกเรื่องนึงจะถามคุณด้วย ผมมีเครื่องคอมอีกเครื่องหนึ่งที่เป็นเครื่องเก่ามาก เป็น HP Desktop AiO PC 160W ซึ่งมีแรมแค่ 4GB ซึ่งเดิมผมใช้ Windows 8.1 แต่เครื่องรันช้ามากจนน่าเบื่อ ผมเลยคิดว่าลองเอามาลง Ubuntu server และ openbox เผื่อจะใช้งานดีขึ้นบ้าง แต่เมื่อผมลง utuntu สำเร็จแล้ว ผมก็สังเกตว่าใน /home/weivo ซึ่งเป็น directory หลัก ไม่มีไฟล์หรือโฟลเดอร์อะไรอยู่ในนั้นเลย และผมคาดหวังว่าเมื่อผม sudo apt install openbox xorg xterm แล้ว ควรจะมี Folder คล้ายๆบน Windows ขึ้นในโฟลเดอร์หลัก เหมือนกับของเครื่อง Lenovo Ideapad5 ในขณะที่ลง openbox ก็ไม่พบว่ามีอะไรผิดปกติ การ install ทั้งหมดก็ราบรื่นดี แต่พอ install เสร็จ ผมลองใช้คำสั่ง dir หรือ ls เพื่อดูข้อมูล ปรากฎว่าในโฟลเดอร์ /home/weivo กลับไม่พบไฟล์หรือโฟลเดอร์ใดๆเลย คุณคิดว่าเป็นเพราะเหตุใด

## Response:
เรื่องนี้ไม่ใช่เรื่องแปลกครับ และเครื่อง HP AiO ของคุณก็ไม่ได้ทำงานผิดปกติด้วย แต่นี่คือความแตกต่างที่ชัดเจนระหว่าง **"Desktop Environment"** (เหมือนใน Lenovo ของคุณ) กับ **"Window Manager"** (Openbox) บนฐานของ **Ubuntu Server** ครับ

สาเหตุที่คุณไม่เห็นโฟลเดอร์ Desktop, Documents, หรือ Downloads ใน `/home/weivo` มีเหตุผลหลักๆ 3 ข้อดังนี้ครับ:
### 1\. Ubuntu Server มาแบบ "หัวโล้น"
Ubuntu Server ถูกออกแบบมาให้เบาที่สุดเพื่อให้รัน Service ต่างๆ ได้เต็มที่ มันจึงไม่ได้สร้างโครงสร้างโฟลเดอร์สำหรับผู้ใช้งานทั่วไป (XDG User Directories) มาให้ตั้งแต่ต้น เพราะในมุมมองของ Server โฟลเดอร์ "Desktop" นั้นไม่มีความจำเป็นครับ

### 2\. Openbox เป็นแค่ "คนจัดระเบียบหน้าต่าง"
ในขณะที่ Lenovo ของคุณอาจจะใช้ GNOME หรือ KDE ซึ่งเป็น **Desktop Environment (DE)** แบบเต็มสูบ ซึ่งพวกนี้จะมีสคริปต์สั่งให้สร้างโฟลเดอร์มาตรฐานให้โดยอัตโนมัติเมื่อ User ล็อกอินครั้งแรก
แต่ **Openbox** เป็นเพียง **Window Manager (WM)** หน้าที่ของมันมีแค่ "วาดขอบหน้าต่าง" และ "จัดการปุ่มย่อ/ขยาย" เท่านั้น มันไม่ได้แถมชุดซอฟต์แวร์จัดการไฟล์หรือตัวสร้างโฟลเดอร์มาตรฐานมาด้วยครับ

### 3\. ไฟล์ที่คุณมองไม่เห็น (Hidden Files)
จริงๆ แล้วใน `/home/weivo` ไม่ได้ว่างเปล่าครับ แต่มันมีไฟล์ที่ขึ้นต้นด้วยจุด `.` (Hidden Files) ซึ่งคำสั่ง `ls` หรือ `dir` ปกติจะมองไม่เห็น ลองใช้คำสั่งนี้ดูครับ:
```
ls -la
```
คุณจะพบไฟล์อย่าง `.bashrc`, `.profile` หรือโฟลเดอร์คอนฟิกของ Openbox (ถ้ามีการรันไปแล้ว) อยู่ในนั้นครับ

* * *

### วิธีแก้: ทำให้โฟลเดอร์เหล่านั้นกลับมา
ถ้าคุณต้องการให้มีโฟลเดอร์ Desktop, Documents, Downloads เหมือนใน Windows หรือ Ubuntu Desktop คุณสามารถติดตั้งเครื่องมือเล็กๆ ที่ชื่อว่า **XDG User Directories** ได้ครับ:
1.  **ติดตั้งเครื่องมือ:**
    ```
    sudo apt install xdg-user-dirs
    ```
2.  **สั่งให้สร้างโฟลเดอร์:**
    ```
    xdg-user-dirs-update
    ```
พอรันคำสั่งนี้เสร็จ แล้วลอง `ls` ดูอีกครั้ง คุณจะเห็นโฟลเดอร์ที่คุณคุ้นเคยปรากฏขึ้นมาทันทีครับ!

* * *

### คำแนะนำเพิ่มเติมสำหรับเครื่อง HP แรม 4GB
การเปลี่ยนมาใช้ Ubuntu Server + Openbox เป็นการตัดสินใจที่ **"ฉลาดมาก"** สำหรับสเปกนี้ครับ เพราะมันจะกินแรมน้อยกว่า Windows 8.1 มหาศาล (น่าจะกินแรมแค่ 200-400MB ตอน Start เครื่องเสร็จ)
แต่เนื่องจากคุณเริ่มจาก Ubuntu Server คุณอาจจะต้องลง "ตัวจัดการไฟล์" (File Manager) เพิ่มเพื่อให้ใช้งานง่ายขึ้น ผมแนะนำ **PCManFM** ครับ มันเบาและเข้ากับ Openbox ได้ดีมาก:
```
sudo apt install pcmanfm
```


## Prompt:
แล้วไฟล์ autostart ของ openbox รวมทั้งข้อมูลต่างๆของ openbox อยู่ที่ไหน

## Response:
นี่คือจุดที่มือใหม่ Openbox มักจะงงกันทุกคนครับ เพราะ Openbox เปรียบเสมือน "บ้านเปล่า" ที่เขาไม่ได้จัดเฟอร์นิเจอร์มาให้เลยแม้แต่ชิ้นเดียว คุณต้องเป็นคนก๊อปปี้ไฟล์ตั้งค่า (Configuration Files) เข้าไปวางเองครับ

โดยปกติแล้ว ไฟล์ข้อมูลและ **autostart** ของ Openbox จะแบ่งเป็น 2 แหล่ง ดังนี้ครับ:
### 1\. แหล่งต้นฉบับ (System-wide)
หลังติดตั้งเสร็จ ไฟล์มาตรฐานจะถูกเก็บไว้ที่นี่ (แต่เราจะไม่แก้ไขที่นี่ เพราะถ้าอัปเดตระบบไฟล์อาจจะถูกเขียนทับ):
> **`/etc/xdg/openbox/`**

ในโฟลเดอร์นี้จะมีไฟล์สำคัญ 4 ตัว:
*   **`rc.xml`**: หัวใจหลัก ใช้ตั้งค่าปุ่มลัด (Shortcuts), ธีม, และพฤติกรรมของหน้าต่าง
*   **`menu.xml`**: จัดการเมนูที่จะปรากฏเวลาคุณ "คลิกขวา" บนหน้าจอ
*   **`autostart`**: ไฟล์สคริปต์ที่รวบรวมคำสั่งให้โปรแกรมทำงานทันทีที่เข้า Openbox (เช่น สั่งให้เปิดแถบ Taskbar หรือตั้งรูป Wallpaper)
*   **`environment`**: ใช้กำหนดค่าตัวแปรระบบต่างๆ

* * *

### 2\. แหล่งใช้งานจริง (User-specific)
Openbox จะมองหาไฟล์ตั้งค่าในโฟลเดอร์ส่วนตัวของคุณที่:
> **`~/.config/openbox/`** (หรือ `/home/weivo/.config/openbox/`)
**แต่เดี๋ยวก่อน!** อย่างที่คุณสังเกตเห็นว่ามัน "ว่างเปล่า" นั่นเพราะระบบไม่ได้สร้างให้คุณอัตโนมัติครับ คุณต้องสร้างมันขึ้นมาเองด้วยคำสั่งนี้:

#### **วิธีสร้างไฟล์คอนฟิกให้ตัวเอง (แนะนำให้ทำทันที):**

ใช้คำสั่งเหล่านี้เพื่อสร้างโฟลเดอร์และก๊อปปี้ไฟล์ต้นฉบับมาเป็นของตัวเองครับ:
```
# 1. สร้างโฟลเดอร์เก็บค่าคอนฟิก
mkdir -p ~/.config/openbox

# 2. ก๊อปปี้ไฟล์มาตรฐานมาวาง
cp /etc/xdg/openbox/* ~/.config/openbox/
```
เมื่อรันเสร็จแล้ว ลองใช้คำสั่ง `ls ~/.config/openbox` ดู คุณจะเห็นไฟล์ทั้ง 4 ตัวโผล่มาให้คุณแก้ไขแล้วครับ!

* * *

### วิธีการใช้งานไฟล์ `autostart`
ถ้าคุณต้องการให้เครื่อง HP แรม 4GB ของคุณเปิดมาแล้วมีแถบด้านล่าง หรือตั้งค่าอะไรบางอย่าง ให้พิมพ์แก้ไขไฟล์นี้:
```
nano ~/.config/openbox/autostart
```
จากนั้นคุณสามารถเพิ่มชื่อโปรแกรมที่ต้องการให้รันตอนเริ่มเครื่องได้เลย เช่น:
```
# ตัวอย่างการเขียนในไฟล์ autostart
tint2 &        # เปิดแถบ Taskbar (ถ้าลงไว้)
nm-applet &    # แสดงไอคอน Wi-Fi (ถ้าลงไว้)
pcmanfm -d &   # รันตัวจัดการไฟล์แบบเบื้องหลัง
dunst &
```
_(อย่าลืมใส่เครื่องหมาย `&` ไว้ข้างหลังคำสั่ง เพื่อให้มันทำงานเป็นเบื้องหลังและไม่ค้างอยู่ที่คำสั่งนั้นครับ)_


สำหรับการติดตั้ง `nm-applet` (ตัวจัดการ Wi-Fi/Network แบบไอคอนมุมจอ) บน Ubuntu Server จะมีขั้นตอนเพิ่มเติมนิดหน่อยครับ เพราะโดยปกติ Ubuntu Server จะใช้ระบบจัดการเครือข่ายที่ชื่อว่า **Netplan** (เน้นพิมพ์คำสั่ง) แต่เจ้า `nm-applet` มันต้องการคุยกับ **NetworkManager** ครับ

นี่คือขั้นตอนการติดตั้งและตั้งค่าให้ใช้งานได้จริงครับ:

### 1\. ติดตั้งแพ็กเกจ

ตัว `nm-applet` จะอยู่ในแพ็กเกจที่ชื่อว่า `network-manager-gnome` ครับ พิมพ์คำสั่งนี้ได้เลย:

```
sudo apt update
sudo apt install network-manager-gnome
```

* * *

### 2\. เปลี่ยนให้ระบบมาใช้ NetworkManager (สำคัญมาก!)

ใน Ubuntu Server เดิมๆ มันจะถูกสั่งให้ใช้ `systemd-networkd` ซึ่งจะทำให้ไอคอน `nm-applet` ขึ้นกากบาทสีแดง (เพราะมันหาตัวควบคุมไม่เจอ) เราต้องไปบอกระบบให้เปลี่ยนมาใช้ NetworkManager แทนครับ

1.  **เปิดไฟล์ตั้งค่า Netplan:** (ชื่อไฟล์อาจจะต่างกันเล็กน้อย ให้กด Tab เพื่อช่วยสะกดได้ครับ)
    ```
    sudo nano /etc/netplan/00-installer-config.yaml
    ```
2.  **แก้ไขไฟล์:** เพิ่มบรรทัด `renderer: NetworkManager` เข้าไปใต้ `network:` ให้หน้าตาเป็นประมาณนี้:
    ```
    network:
      version: 2
      renderer: NetworkManager
    ```
    _(ระวังเรื่องการเคาะ Spacebar ให้ตรงกันนะครับ ย้ำว่าห้ามใช้ Tab ในไฟล์ .yaml)_
3.  **บันทึกและกดใช้งาน:** กด `Ctrl+O` (Enter) และ `Ctrl+X` ออกมา แล้วพิมพ์:
        ```
    sudo netplan apply
    ```

### 3\. สั่งให้ nm-applet ทำงานอัตโนมัติใน Openbox
เพื่อให้ไอคอน Wi-Fi โผล่มาทุกครั้งที่คุณเปิดเครื่อง (เข้า Openbox) ให้เอาไปใส่ในไฟล์ `autostart` ที่เราเพิ่งสร้างกันในข้อที่แล้วครับ:

1.  **เปิดไฟล์ autostart:**
    ```bash
    nano ~/.config/openbox/autostart
    ```
2.  **เพิ่มบรรทัดนี้ลงไปที่ท้ายไฟล์:**
    ```bash
    nm-applet &
    ```
3.  **บันทึกและปิดไฟล์**

---

### 4. ติดตั้ง Notification Daemon (ถ้าไอคอนไม่ขึ้น)
บางครั้ง `nm-applet` ต้องการระบบแจ้งเตือน (Notifications) เพื่อให้ทำงานได้สมบูรณ์บนหน้าจอที่ว่างเปล่าอย่าง Openbox แนะนำให้ลงตัวนี้เพิ่มด้วยครับ:
```bash
sudo apt install dunst
````
และเพิ่ม `dunst &` ลงในไฟล์ `autostart` ของคุณด้วยเช่นกัน

* * *

### สรุป
ตอนนี้เครื่อง HP ของคุณจะมี:
*   **NetworkManager** เป็นตัวคุมเน็ต
*   **nm-applet** เป็นตัวโชว์ไอคอนและเลือก Wi-Fi
*   **dunst** เป็นตัวคอยเด้งข้อความบอกว่า "เชื่อมต่อแล้ว"

**ข้อควรระวัง:** ถ้าคุณเชื่อมต่อเน็ตผ่านสาย LAN อยู่แล้วตอนทำ ขั้นตอน `netplan apply` อาจจะทำให้เน็ตหลุดไปชั่วครู่ก่อนจะต่อใหม่ผ่าน NetworkManager ไม่ต้องตกใจนะครับ
