ในการใช้งาน Openbox บน Linux การสลับภาษา (Input Method) มักไม่ได้ถูกกำหนดโดยตัว Window Manager (Openbox) โดยตรง แต่จะขึ้นอยู่กับ **Keyboard Layout Handler** ที่คุณเลือกใช้ นี่คือวิธีการตั้งค่าและคีย์ลัดที่นิยมใช้ครับ:

---

## 1\. ตั้งค่าผ่านคีย์บอร์ดโดยตรง (XKB)

หากคุณไม่ได้ใช้โปรแกรมช่วยจัดการตัวอื่น คุณสามารถใช้คำสั่ง `setxkbmap` เพื่อกำหนดคีย์สลับภาษา (เช่น Alt+Shift หรือ Caps Lock) ได้โดยใส่คำสั่งในไฟล์ `~/.config/openbox/autostart`

### ตัวอย่างคำสั่งสลับด้วย Alt+Shift:

```

setxkbmap -layout "us,th" -option "grp:alt_shift_toggle" &

```

### ตัวอย่างคำสั่งสลับด้วยปุ่ม Grave Accent (ปุ่มตัวหนอน ~):

```

setxkbmap -layout "us,th" -option "grp:grave_toggle" &

```

---

## 2\. ใช้โปรแกรมจัดการ Input Method (แนะนำ)

สำหรับ Openbox ซึ่งไม่มี Panel บอกสถานะภาษาในตัว การใช้โปรแกรมเสริมจะช่วยให้สลับภาษาได้ง่ายและเสถียรกว่า:

### IBus (Intelligent Input Bus)

เป็นที่นิยมมากที่สุดสำหรับภาษาไทย:

1.  ติดตั้ง: `sudo apt install ibus ibus-gtk ibus-thai`
    
2.  เพิ่มคำสั่ง `ibus-daemon -drx` ในไฟล์ `autostart` ของ Openbox
    
3.  ตั้งค่าผ่านคำสั่ง `ibus-setup` เพื่อเลือกคีย์ลัด (เช่น **Super+Space** หรือคีย์ที่ต้องการ)
    

### Fcitx / Fcitx5

ยืดหยุ่นและทำงานได้ดีกับแอปพลิเคชันหลายประเภท:

1.  ติดตั้ง: `sudo apt install fcitx5 fcitx5-thai`
    
2.  เพิ่มคำสั่ง `fcitx5 -d` ในไฟล์ `autostart`
    
3.  ตั้งค่าคีย์ลัดผ่าน `fcitx5-config-qt`
    

---

## 3\. สรุปคีย์ลัดมาตรฐานที่มักใช้กัน

หากคุณติดตั้งระบบเหล่านี้แล้ว คีย์เริ่มต้นมักจะเป็นอย่างใดอย่างหนึ่งดังนี้:

| โปรแกรม / ระบบ | คีย์ลัดมาตรฐาน |
| --- | --- |
| **XKB (System Default)** | `Alt` + `Shift` หรือ `Ctrl` + `Shift` |
| **IBus** | `Super` (Windows key) + `Space` |
| **Fcitx** | `Ctrl` + `Space` |
| **ปุ่มตัวหนอน (เฉพาะไทย)** | `Grave Accent` (ต้องตั้งค่าเพิ่มเอง) |

---

### วิธีแก้ไขไฟล์ Autostart ของ Openbox

เพื่อให้คีย์ลัดทำงานทุกครั้งที่เปิดเครื่อง ให้แก้ไขไฟล์ดังนี้:

1.  เปิด Terminal
    
2.  พิมพ์ `nano ~/.config/openbox/autostart`
    
3.  เพิ่มบรรทัดคำสั่งที่เลือกไว้ (เช่น `setxkbmap...`) ลงไปที่ท้ายไฟล์
    
4.  บันทึกและ Restart Openbox หรือ Log out แล้วเข้าใหม่ครับ

หากคุณเลือกใช้ **IBus** ในการจัดการการสลับภาษา คุณ**ไม่จำเป็น**ต้องใช้คำสั่ง `setxkbmap` เพื่อตั้งค่าคีย์ลัดครับ เพราะ IBus จะทำหน้าที่เข้ามาควบคุมเลย์เอาต์คีย์บอร์ดแยกจากระบบ XKB ปกติ

ความแตกต่างคือ:

-   `setxkbmap`: เป็นการตั้งค่าที่ระดับระบบ X Window (Low-level)
    
-   `IBus`: เป็นโปรแกรมจัดการ Input Method (High-level) ซึ่งมีตัวเลือกตั้งค่าใน GUI ของตัวเอง
    

---

### วิธีตั้งค่า Windows + Space ใน IBus

หากคุณต้องการใช้ IBus ให้ทำตามขั้นตอนดังนี้แทนครับ:

1.  **เปิดการตั้งค่า IBus:** พิมพ์คำสั่งใน Terminal:
    
    ```

    ibus-setup
    
    ```

    
2.  **ไปที่แท็บ "General":** มองหาหัวข้อ **Keyboard Shortcuts** > **Next input method**
    
3.  **แก้ไขคีย์ลัด:**
    
    -   คลิกที่ปุ่มจุดสามจุด (`...`)
        
    -   กดปุ่ม **Super** (Windows Key) ค้างไว้แล้วกด **Space**
        
    -   ระบบจะแสดงคำว่า `<Super>space`
        
    -   กด Add และ OK
        

---

### สิ่งที่ต้องใส่ใน Openbox `autostart`

แทนที่จะใช้ `setxkbmap` ให้คุณใช้คำสั่งเพื่อเรียก IBus Daemon ขึ้นมาทำงานตอน Login แทน โดยเพิ่มบรรทัดนี้ลงใน `~/.config/openbox/autostart`:

```

# เรียกใช้งาน IBus Daemon
ibus-daemon -drx &

```

---

### ทำไมถึงไม่ใช้ setxkbmap คู่กับ IBus?

หากคุณรันคำสั่ง `setxkbmap -option grp:win_space_toggle` ไปด้วย มันจะเกิดการ**ขัดแย้งกัน (Conflict)** ระหว่างตัวระบบ X11 กับ IBus ผลที่ได้คือบางครั้งภาษาจะเปลี่ยนแต่สถานะใน IBus ไม่เปลี่ยน หรือคีย์ลัดอาจจะไม่ทำงานเลย

**สรุป:**

-   ถ้าใช้ **IBus**: ตั้งค่าผ่าน `ibus-setup` และไม่ต้องยุ่งกับ `setxkbmap`
    
-   ถ้าจะใช้ **setxkbmap** (ไม่ใช้ IBus): จะไม่มีตัวบอกสถานะภาษาบนจอ (Tray Icon) ยกเว้นจะหาโปรแกรมอื่นมาเสริมครับ

หากคุณต้องการใช้ `setxkbmap` เพื่อตั้งค่าให้ปุ่ม **Windows + Space** ทำหน้าที่สลับภาษาโดยตรง (ไม่ผ่าน IBus หรือโปรแกรมอื่น) คุณต้องระบุออปชันชื่อ `grp:win_space_toggle` ครับ

ใช้คำสั่งใน Terminal เพื่อทดสอบทันที:

```

setxkbmap -layout "us,th" -option "grp:win_space_toggle"

```

---

### รายละเอียดของคำสั่ง:

-   **`-layout "us,th"`**: กำหนดเลย์เอาต์คีย์บอร์ดที่ต้องการสลับ (ภาษาอังกฤษ และ ภาษาไทย)
    
-   **`-option "grp:win_space_toggle"`**: เป็นตัวกำหนดว่าให้ใช้ปุ่ม **Super (Windows Key) + Space** ในการสลับระหว่างเลย์เอาต์เหล่านั้น
    

---

### วิธีทำให้มีผลถาวรใน Openbox

เมื่อทดสอบแล้วพอใจ ให้คุณนำคำสั่งไปใส่ไว้ในไฟล์ `autostart` เพื่อให้ระบบเรียกใช้งานทุกครั้งที่เปิดเครื่อง:

1.  เปิดไฟล์: `nano ~/.config/openbox/autostart`
    
2.  เพิ่มบรรทัดนี้ลงไป (อย่าลืมใส่ `&` ต่อท้าย):
    
    ```

    setxkbmap -layout "us,th" -option "grp:win_space_toggle" &
    
    ```

    
3.  บันทึกและปิดไฟล์ (Ctrl+O, Enter, Ctrl+X)
    

---

### ข้อสังเกตเพิ่มเติม

-   **ไม่มีสัญลักษณ์บอกภาษา:** การใช้ `setxkbmap` เพียวๆ จะไม่มีไอคอนบอกสถานะที่มุมจอว่าตอนนี้เป็นภาษาอะไร หากคุณต้องการตัวบอกภาษาแบบเบาๆ สำหรับ Openbox แนะนำให้ลองติดตั้งโปรแกรมเพิ่ม เช่น `fbxkb` หรือ `gxkb`
    
-   **การล้างค่า Option:** หากคุณเคยพิมพ์คำสั่งอื่นไปก่อนหน้าแล้วมันเกิดอาการซ้อนกัน (เช่น สลับด้วยปุ่มตัวหนอนด้วย Windows+Space ด้วย) ให้ล้างค่าเก่าก่อนด้วยคำสั่ง:
    
    ```

    setxkbmap -option ""
    
    ```

    
    แล้วค่อยพิมพ์คำสั่งที่มี `win_space_toggle` ลงไปใหม่อีกครั้งครับ

การลบ Python package ที่ติดตั้งผ่าน `pip` บน Ubuntu Server สามารถทำได้ง่ายๆ ด้วยคำสั่ง `uninstall` ครับ

### 1\. คำสั่งลบ PyTorch มาตรฐาน

หากคุณติดตั้งมาในชื่อ `torch` ให้ใช้คำสั่งนี้:

```

pip uninstall torch

```

---

### 2\. กรณีที่ติดตั้งองค์ประกอบอื่นมาด้วย (เช่น torchvision, torchaudio)

ปกติเวลาใช้งาน PyTorch เรามักจะติดตั้ง library เสริมมาด้วย เพื่อความสะอาดของระบบ แนะนำให้ลบออกไปพร้อมกันครับ:

```

pip uninstall torch torchvision torchaudio

```

---

### 3\. ตรวจสอบให้แน่ใจว่าลบออกหมดแล้ว

หลังจากรันคำสั่งลบแล้ว คุณสามารถตรวจสอบว่ายังมีชื่อ `torch` ค้างอยู่ในรายการ package หรือไม่ด้วยคำสั่ง:

```

pip list | grep torch

```

*ถ้าไม่มีชื่อปรากฏขึ้นมา แสดงว่าลบออกเรียบร้อยแล้วครับ*

---

### ข้อควรระวัง

-   **Permissions:** หากคุณติดตั้งด้วยสิทธิ์ root (ซึ่งไม่แนะนำ) คุณอาจต้องเติม `sudo` ข้างหน้า เช่น `sudo pip uninstall torch`
    
-   **Virtual Environments:** หากคุณใช้งานผ่าน Virtual Environment (เช่น venv หรือ conda) **อย่าลืม activate environment** นั้นก่อนใช้คำสั่งลบ เพื่อไม่ให้ไปกระทบกับตัวแปรภาษา Python ของระบบหลัก (System Python)
    
-   **Cache:** การลบ package จะลบตัวไฟล์ที่ติดตั้ง แต่ไฟล์ cache ที่ดาวน์โหลดมาอาจจะยังอยู่ ถ้าต้องการล้างพื้นที่เพิ่มสามารถใช้ `pip cache purge` ได้ครับ
    

คุณกำลังจะเปลี่ยนไปใช้เวอร์ชันอื่น หรือต้องการย้ายไปรันบน hardware ตัวไหนเป็นพิเศษไหมครับ?

การถอนการติดตั้ง **IBus** บน Ubuntu Server หรือเครื่องที่ใช้ Openbox สามารถทำได้ด้วยคำสั่ง `apt` ครับ แต่ต้องระวังเล็กน้อยหากคุณมี Desktop Environment อื่นติดตั้งอยู่ด้วย (เช่น GNOME) เพราะ IBus เป็นส่วนประกอบหลักของระบบเหล่านั้น

### 1\. คำสั่งถอนการติดตั้งมาตรฐาน

หากคุณต้องการลบเฉพาะตัวโปรแกรม IBus และ configuration ที่เกี่ยวข้อง:

```

sudo apt remove ibus ibus-thai

```

### 2\. ลบแบบหมดจด (รวมไฟล์ตั้งค่า)

หากต้องการลบไฟล์คอนฟิกทั้งหมดออกไปด้วย:

```

sudo apt purge ibus ibus-thai

```

### 3\. ล้าง Dependencies ที่ไม่ได้ใช้งาน

หลังจากลบตัวหลักออกแล้ว มักจะมี package เสริมที่ถูกดึงมาตอนติดตั้งแต่ไม่ได้ใช้แล้วค้างอยู่ ให้ใช้คำสั่งนี้เพื่อเคลียร์พื้นที่ครับ:

```

sudo apt autoremove

```

---

### ข้อควรระวัง (สำคัญมาก)

-   **สำหรับผู้ใช้ GNOME:** หากคุณใช้ Ubuntu เวอร์ชันมาตรฐานที่มี GNOME เป็น Desktop หลัก **ห้ามลบ IBus** เด็ดขาด เพราะ GNOME พึ่งพา IBus ในการทำงานหลายส่วน การลบอาจทำให้ Desktop พังหรือเข้าหน้าจอไม่ได้
    
-   **สำหรับ Openbox:** คุณสามารถลบได้ตามสบายครับ เพราะ Openbox ไม่ได้ยึดติดกับ Input Method ตัวใดตัวหนึ่ง
    

### อย่าลืมแก้ไขไฟล์ Autostart

หลังจากถอนการติดตั้งแล้ว อย่าลืมเข้าไปลบหรือใส่เครื่องหมาย `#` หน้าบรรทัดที่เรียกใช้ IBus ในไฟล์คอนฟิกของ Openbox ด้วยนะครับ:
