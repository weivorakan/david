การเปลี่ยนชื่อเครื่อง (Hostname) บน **Ubuntu Server 26.04 LTS** นั้นทำได้ง่ายๆ ผ่าน Command Line ครับ โดยปกติจะมี 2 ส่วนที่ต้องจัดการ คือชื่อที่ระบบใช้ (Static Hostname) และการประกาศตัวในไฟล์ที่ช่วยเรื่องการค้นหาชื่อใน Network Local ครับ

นี่คือขั้นตอนที่ถูกต้องและเป็นระเบียบที่สุดครับ:

---

### 1\. เปลี่ยน Hostname ด้วยคำสั่ง `hostnamectl`

คำสั่งนี้เป็นวิธีมาตรฐานของ systemd ซึ่งจะเปลี่ยนชื่อเครื่องแบบถาวร (Static) ให้ทันที

```

sudo hostnamectl set-hostname YOUR_NEW_NAME

```

*เปลี่ยน `YOUR_NEW_NAME` เป็นชื่อที่คุณต้องการ (แนะนำให้ใช้ภาษาอังกฤษ ตัวพิมพ์เล็ก และไม่มีช่องว่าง)*

---

### 2\. แก้ไขไฟล์ `/etc/hosts`

เพื่อให้แอปพลิเคชันภายในเครื่องและการ Resolve ชื่อในเครือข่ายบางส่วนทำงานได้ถูกต้อง คุณควรไปอัปเดตไฟล์ hosts ด้วยครับ

1.  เปิดไฟล์ด้วย Text Editor:
    
    ```

    sudo nano /etc/hosts
    
    ```

    
2.  มองหาบรรทัดที่เขียนว่า `127.0.1.1` แล้วเปลี่ยนชื่อเดิมให้เป็นชื่อใหม่:
    
    ```

    127.0.0.1   localhost
    127.0.1.1   YOUR_NEW_NAME
    
    ```

    
3.  กด **Ctrl + O** (Save) และ **Ctrl + X** (Exit)
    

---

### 3\. การทำให้ Network มองเห็นชื่อนี้ (mDNS)

หากคุณต้องการให้เครื่องอื่นใน Network เดียวกันพิมพ์ `ping YOUR_NEW_NAME.local` แล้วเจอเครื่องเราเลย โดยไม่ต้องตั้งค่า DNS Server ให้ยุ่งยาก คุณควรติดตั้งบริการ **Avahi** (โปรโตคอล mDNS/Zeroconf) ครับ

1.  ติดตั้ง Avahi Daemon:
    
    ```

    sudo apt update
    sudo apt install avahi-daemon
    
    
    ```

    

```

2. ตรวจสอบสถานะ:
   ```bash
   sudo systemctl enable --now avahi-daemon

```

---

### 4\. ตรวจสอบผลลัพธ์

หลังจากทำเสร็จแล้ว ให้ลองรันคำสั่ง:

```

hostnamectl

```

และลอง Logout แล้ว Login ใหม่ หรือใช้คำสั่ง `exec bash` เพื่อให้ชื่อใหม่แสดงผลบน Prompt ของ Terminal ครับ

> **โน้ตสำคัญ:** หากคุณใช้งานบน Cloud Provider (เช่น AWS, Azure, Google Cloud) บางครั้งชื่อเครื่องอาจถูกเขียนทับด้วย Metadata Service ของผู้ให้บริการเมื่อมีการ Restart เครื่อง ถ้าเป็นกรณีนั้น คุณอาจต้องไปแก้ที่ไฟล์ `/etc/cloud/cloud.cfg` โดยเปลี่ยน `preserve_hostname: false` ให้เป็น `true` ครับ
