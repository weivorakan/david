How to setup TTY or GUI
เพื่อดูว่าตอนนี้ระบบใช้อะไรอยู่ เช่น Ubuntu Terminal(tty) หรือ Wayland(GUI)
echo $XDG_SESSION_TYPE

**คำสั่งให้กลับมาใช้ Ubuntu Terminal
sudo systemctl set-default multi-user.target
sudo reboot

**หากวันไหนอยากกลับมาใช้หน้าจอ GUI (Wayland/X11) เหมือนเดิม**
sudo systemctl set-default graphical.target
sudo reboot
