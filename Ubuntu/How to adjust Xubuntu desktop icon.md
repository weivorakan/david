สำหรับการปรับแต่งระยะห่าง (Spacing) ของไอคอนบนหน้าจอ Desktop ของ Xubuntu 24.04 (ซึ่งใช้สภาพแวดล้อม Desktop แบบ **Xfce**) นั้น ไม่ได้มีแถบเลื่อนให้ปรับได้โดยตรงในเมนู Settings ปกติ แต่คุณสามารถทำได้ผ่าน **Desktop Settings** และการแก้ไขไฟล์ **CSS** ครับ

นี่คือวิธีจัดการที่ได้ผลที่สุด:

---

### 1\. ปรับขนาดไอคอนและฟอนต์ (วิธีพื้นฐาน)

ก่อนจะไปแก้โค้ด ลองเช็กดูก่อนว่าการปรับขนาดไอคอนช่วยให้ดูดีขึ้นหรือไม่:

1.  คลิกขวาที่ว่างบนหน้าจอ เลือก **Desktop Settings...**
    
2.  ไปที่แท็บ **Icons**
    
3.  ปรับค่า **Icon size** (ค่าเริ่มต้นมักอยู่ที่ 48)
    
4.  ลองปรับ **Use custom font size** เพื่อลดขนาดพื้นที่ข้อความใต้ไอคอน
    

---

### 2\. ปรับ Spacing ผ่านการแก้ไขไฟล์ CSS (วิธีที่แม่นยำที่สุด)

Xfce ใช้ GTK ในการแสดงผล คุณสามารถกำหนดระยะห่าง (Padding) ได้เองโดยการสร้างหรือแก้ไขไฟล์ `gtk.css` ตามขั้นตอนดังนี้ครับ:

1.  เปิด **Terminal** (Ctrl+Alt+T)
    
2.  เปิดไฟล์ CSS ด้วย Text Editor (ในที่นี้ใช้ Mousepad):
    
    ```

    mousepad ~/.config/gtk-3.0/gtk.css
    
    ```

    
3.  คัดลอก Code ด้านล่างนี้ไปวางในไฟล์:
    

```

/* ปรับระยะห่างระหว่างไอคอนบน Desktop */
XfdesktopIconView {
    -XfdesktopIconView-cell-spacing: 10;
    -XfdesktopIconView-cell-padding: 8;
    -XfdesktopIconView-cell-text-width-proportion: 2.0;
}

/* ปรับระยะห่างภายใน (Padding) ของแต่ละไอคอน */
.rubberband,
XfdesktopIconView.view {
    padding: 10px;
}

```

**คำอธิบายค่าต่างๆ:**

-   **cell-spacing:** ระยะห่างระหว่าง "ช่อง" ของแต่ละไอคอน
    
-   **cell-padding:** ระยะห่างจากขอบไอคอนถึงตัวไอคอนเอง
    
-   **cell-text-width-proportion:** ความกว้างของพื้นที่ข้อความใต้ไอคอน (ปรับให้กว้างขึ้นเพื่อป้องกันชื่อไฟล์ถูกตัด)
    

1.  **Save** ไฟล์ให้เรียบร้อย
    
2.  **Restart การทำงานของ Desktop** เพื่อดูความเปลี่ยนแปลง โดยพิมพ์คำสั่งใน Terminal:
    
    ```

    xfdesktop --reload
    
    ```

    

---

### 3\. การจัดเรียงแบบ Grid (Snap to Grid)

หากไอคอนวางสะเปะสะปะและคุณต้องการให้มันลงล็อก:

1.  คลิกขวาที่หน้าจอ -> **Desktop Settings...** -> แท็บ **Icons**
    
2.  ตรวจสอบว่าติ๊กถูกที่ **Snap to grid** แล้ว
    
3.  หากคุณต้องการเลื่อนไอคอนได้อย่างอิสระมากขึ้น ให้ลดขนาด **Icon size** ลง จะทำให้ "ตาราง" (Grid) ถี่ขึ้น ทำให้วางไอคอนได้ชิดกันมากขึ้นครับ
    

ถ้าทำตามขั้นตอน CSS แล้วยังรู้สึกว่าไม่พอดี ลองปรับตัวเลขในไฟล์ `gtk.css` เพิ่มหรือลดดูครับ (แนะนำให้ปรับทีละ 2-5 pixel) แล้วสั่ง `xfdesktop --reload` ทุกครั้งครับ
