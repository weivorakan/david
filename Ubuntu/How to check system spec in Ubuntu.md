สำหรับการดูข้อมูลสเปคเครื่อง (System Specifications) ใน **Xubuntu** นั้นทำได้หลายวิธีครับ ขึ้นอยู่กับว่าคุณอยากดูแบบคร่าวๆ หรือเจาะลึกถึงรหัสรุ่นของ Hardware เลย

นี่คือวิธีที่ง่ายและเป็นที่นิยมที่สุดครับ:

---

### 1\. ดูผ่านหน้าจอ GUI (ง่ายที่สุด)

หากคุณไม่อยากพิมพ์คำสั่ง ให้ใช้เครื่องมือที่มีมาให้ในระบบ:

-   **Settings Manager:** ไปที่เมนู (ไอคอนหนู) > **Settings** > **About Me** หรือ **System Information** (ขึ้นอยู่กับเวอร์ชันของ Xubuntu) ซึ่งจะบอกข้อมูล CPU และ RAM เบื้องต้น
    
-   **Task Manager:** เปิด **Task Manager** ขึ้นมา แล้วไปที่แท็บ **Resources** คุณจะเห็นการทำงานของ CPU, RAM และเครือข่ายแบบ Real-time
    

---

### 2\. ดูผ่าน Terminal (ละเอียดและรวดเร็ว)

การใช้คำสั่งใน Terminal จะช่วยให้คุณเห็นสเปคที่ชัดเจนกว่ามากครับ

#### **แบบสรุปสวยงาม (Neofetch)**

ถ้าเครื่องคุณยังไม่มี ให้ติดตั้งด้วยคำสั่ง `sudo apt install neofetch` จากนั้นพิมพ์:

```

neofetch

```

เครื่องมือนี้จะโชว์โลโก้ Xubuntu พร้อมสเปคหลักๆ เช่น OS, Kernel, Uptime, Packages, Shell, Resolution, DE, WM, CPU, GPU และ Memory

#### **แบบเจาะลึก Hardware (lscpu & free)**

-   **ดูรายละเอียด CPU:** พิมพ์ `lscpu`
    
-   **ดูขนาด RAM:** พิมพ์ `free -h` (ตัว `-h` จะทำให้อ่านง่ายขึ้นเป็นหน่วย GB/MB)
    
-   **ดูข้อมูลอุปกรณ์ทั้งหมด:** พิมพ์ `inxi -F` (หากไม่มีให้ลงด้วย `sudo apt install inxi`) คำสั่งนี้จะบอกทุกอย่างตั้งแต่ Hard drive ไปจนถึงการ์ดเสียง
    

---

### 3\. ติดตั้งโปรแกรมเพิ่มเติม (สำหรับสายกราฟิก)

ถ้าคุณชอบหน้าตาแบบโปรแกรม CPU-Z ใน Windows แนะนำให้ลงตัวนี้ครับ:

-   **CPU-X:** เป็นตัวที่ใกล้เคียงกับ CPU-Z มากที่สุด
    
    -   ติดตั้ง: `sudo apt install cpu-x`
        
-   **Hardinfo:** ตัวนี้จะแสดงรายงานสเปคอย่างละเอียดและสามารถทำ Benchmark ทดสอบความเร็วเครื่องได้ด้วย
    
    -   ติดตั้ง: `sudo apt install hardinfo`
