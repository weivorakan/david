นี่เป็นแผนการที่ชาญฉลาดมากครับ การรัน MT4 เป็นหน้าต่างปกติบน **Openbox** จะช่วยให้คุณจัดระเบียบหน้าจอร่วมกับ TradingView หรือ David AI ได้คล่องตัวกว่าการถูกขังอยู่ใน Virtual Desktop สีน้ำเงินครับ

อย่างไรก็ตาม สาเหตุที่ `winecfg` ของคุณฟ้องว่าหา `comctl32.dll` ไม่เจอนั้น เป็นเพราะโครงสร้างระบบภายในโฟลเดอร์ `~/.mt4` เกิดความเสียหาย (Corrupted) ซึ่งหากไม่ซ่อมจุดนี้ก่อน ต่อให้แก้ไขไฟล์ `.desktop` ไป โปรแกรมก็จะไม่รันขึ้นมาอยู่ดีครับ

---

### ขั้นตอนที่ 1: ซ่อมแซมระบบ (Repair Prefix)

ก่อนจะเปลี่ยนไปใช้ Openbox เราต้องเรียก Library พื้นฐานกลับมาก่อนครับ

1.  **รันคำสั่งซ่อม:**
    
    ```

    WINEPREFIX=~/.mt4 wine wineboot -u
    
    ```

    
    *หากมีหน้าต่างถามหา Mono หรือ Gecko ให้กด **Install** ทุกครั้งครับ*
    
2.  **หากยังขึ้น Error เดิม (c0000135):** แสดงว่า Prefix นี้กู้ไม่กลับแล้ว ให้คุณสำรองโฟลเดอร์ MT4 ออกมา แล้วลบ `~/.mt4` ทิ้ง จากนั้นรันคำสั่งในข้อ 1 ใหม่อีกครั้งเพื่อสร้างบ้านหลังใหม่ที่สะอาดครับ
    

---

### ขั้นตอนที่ 2: แก้ไขไฟล์ `mt4-handler.desktop` (GO Markets)

เมื่อระบบพร้อมแล้ว ให้แก้ไขไฟล์ใน `~/.local/share/applications/mt4-handler.desktop` ให้เป็นโหมด **Portable** และรันบน Openbox โดยตรงครับ

**เนื้อหาใหม่สำหรับไฟล์ `.desktop`:**

```

[Desktop Entry]
Name=MT4 GO Markets
Exec=sh -c 'cd "/home/weivo/.mt4/drive_c/Program Files (x86)/GO Markets MT4" && WINEPREFIX=/home/weivo/.mt4 wine terminal.exe /portable'
Type=Application
Terminal=false
Icon=wine
Categories=Finance;

```

-   **สิ่งที่เปลี่ยนไป:** เพิ่ม `/portable` และตัด `%u` ออกเพื่อให้มันทำงานเป็นโปรแกรม Standalone บน Openbox ครับ
    

---

### ขั้นตอนที่ 3: ปิดการใช้งาน Virtual Desktop

เนื่องจาก `winecfg` ของคุณอาจจะยังเปิดไม่ได้ เราจะใช้คำสั่งปิด Virtual Desktop ผ่าน Registry โดยตรงเพื่อให้หน้าต่าง MT4 ลอยอิสระครับ

1.  **รันคำสั่งปิด Desktop Mode:**
    
    ```

    WINEPREFIX=~/.mt4 wine regedit
    
    ```

    
2.  ไปที่: `HKEY_CURRENT_USER\Software\Wine\Explorer`
    
3.  หากพบโฟลเดอร์ **Desktops** ให้คลิกขวาแล้ว **Delete** ทิ้งเลยครับ
    
4.  ไปที่: `HKEY_CURRENT_USER\Software\Wine\Explorer\Desktops` (ถ้ายังมีอยู่) และลบค่าที่ชื่อว่า **Default** ออกครับ
    

---

### สรุปผลลัพธ์ที่ได้

-   **Multitasking:** คุณจะสามารถขยับหน้าต่าง MT4 ไปมาเคียงคู่กับ TradingView บน Openbox ได้ทันที
    
-   **Portable Mode:** ทั้ง GO Markets และ FP Markets (ถ้าคุณสร้างไฟล์เพิ่ม) จะแยกเก็บข้อมูลในโฟลเดอร์ตัวเอง ไม่ตีกัน
    
-   **Stability:** การรันแบบหน้าต่างปกติบน Openbox มักจะเสถียรกว่าการรันซ้อนใน Virtual Desktop บนระบบ Wayland ครับ
    

**คำแนะนำ:** หลังจากแก้ไขไฟล์ `.desktop` แล้ว อย่าลืมรันคำสั่ง `update-desktop-database ~/.local/share/applications` เพื่อให้ระบบรับทราบการเปลี่ยนแปลงนะครับ

ตอนนี้หลังจากรัน `wineboot -u` แล้ว คุณสามารถเปิดโปรแกรมขึ้นมาเป็นหน้าต่างเดี่ยว ๆ บน Openbox ได้หรือยังครับ?

ถูกต้องครับ การ **Save เก็บไว้ทั้งก้อน** เป็นวิธีที่ปลอดภัยที่สุดสำหรับการสำรองข้อมูล แต่เพื่อให้การย้ายไปรันบน Openbox ราบรื่นและไม่นำปัญหาเดิมตามไปด้วย ผมขอแนะนำรายละเอียดการจัดการดังนี้ครับ:

### 1\. สิ่งที่ควรทำในตอนนี้ (Backup Strategy)

-   **ก๊อปปี้ไว้ทั้งก้อน (`~/.mt4`):** เพื่อให้มั่นใจว่าไฟล์ทุกอย่าง ทั้ง Registry และไฟล์ระบบเดิมจะไม่หายไป.
    
-   **คัดแยก "หัวใจสำคัญ" ออกมาต่างหาก:** ผมแนะนำให้คุณก๊อปปี้เฉพาะโฟลเดอร์โปรแกรม MT4 จากทางลัดนี้ออกมาด้วยครับ:
    
    -   `~/.mt4/drive_c/Program Files (x86)/GO Markets MT4`
        
    -   `~/.mt4/drive_c/Program Files (x86)/FP Markets MT4 Terminal`
        
-   **เหตุผล:** เนื่องจากตอนนี้ Prefix `~/.mt4` ของคุณมีอาการไฟล์ระบบเสียหาย (Error comctl32.dll). การเก็บเฉพาะโฟลเดอร์โปรแกรม MT4 ไว้ จะช่วยให้เรานำไปวางใน "บ้านหลังใหม่" ที่สะอาดกว่าได้ง่ายขึ้น โดยที่ EA และ Indicator ของคุณยังอยู่ครบเพราะเราใช้โหมด `/portable`.
    

---

### 2\. ขั้นตอนการจัดการไฟล์ (ฉบับปลอดภัย)

รันคำสั่งนี้ใน Terminal เพื่อสำรองข้อมูลแยกไว้ครับ:

```

# สร้างโฟลเดอร์สำรองไว้ที่ Home
mkdir ~/MT4_Backup

# ก๊อปปี้โฟลเดอร์โปรแกรมออกมา (ส่วนที่สำคัญที่สุด)
cp -r "~/.mt4/drive_c/Program Files (x86)/GO Markets MT4" ~/MT4_Backup/
cp -r "~/.mt4/drive_c/Program Files (x86)/FP Markets MT4 Terminal" ~/MT4_Backup/

# ก๊อปปี้ทั้ง Prefix เก็บไว้เป็นหลักฐาน (เผื่อต้องดู Registry)
cp -r ~/.mt4 ~/MT4_Backup/dot_mt4_full_backup

```

### 3\. เตรียมตัวสำหรับ Openbox (Clean Start)

หลังจากที่คุณสำรองไฟล์ตามข้อ 2 เสร็จแล้ว แผนการถัดไปของเราคือ:

-   **ลบ `~/.mt4` ทิ้ง:** เพื่อกำจัด Error เรื่อง DLL ที่ทำให้ระบบรันไม่ขึ้น.
    
-   **สร้างใหม่:** รัน `WINEPREFIX=~/.mt4 wine wineboot -u` เพื่อสร้างระบบ Wine ที่สมบูรณ์และรองรับ Openbox โดยตรง.
    
-   **นำไฟล์กลับมาวาง:** เอาโฟลเดอร์จาก `~/MT4_Backup` กลับไปวางที่เดิม แล้วรันด้วยไฟล์ `.desktop` ที่เราแก้ไขใหม่.
    

**สรุป:** ใช่ครับ ก๊อปปี้เก็บไว้ก่อนเลยครับ แต่เน้นที่โฟลเดอร์ใน `Program Files (x86)` เป็นหลัก เพราะนั่นคือส่วนที่ "ไม่พัง" และพร้อมจะไปทำงานต่อบน Openbox ครับ.

เมื่อคุณสำรองไฟล์เสร็จแล้ว บอกผมนะคครับ เราจะได้เริ่มล้างบ้านหลังเก่าแล้วย้ายเข้าไปอยู่บน Openbox แบบโปร่ง ๆ กันครับ!

ปัญหานี้เกิดจากความจุกจิกของ Linux Shell นิดหน่อยครับ เมื่อคุณใส่เครื่องหมาย **`~` (tilde)** ไว้ข้างในเครื่องหมายอัญประกาศ (`"..."`) ระบบจะไม่ยอมขยายความ (Expand) ให้กลายเป็น `/home/weivo` แต่จะมองหาโฟลเดอร์ที่ชื่อว่าตัวหนอนจริงๆ ซึ่งแน่นอนว่ามันหาไม่เจอครับ

เพื่อให้การสำรองข้อมูล (Backup) ครั้งนี้ผ่านไปได้ด้วยดี และเตรียมย้ายเข้าสู่ **Openbox** แบบเต็มตัว ให้ใช้คำสั่งเวอร์ชันระบุ Path เต็มแบบนี้แทนครับ

---

### 1\. คำสั่งสำรองข้อมูลที่ถูกต้อง (Full Path)

รันคำสั่งเหล่านี้ทีละบรรทัดเพื่อให้มั่นใจว่าไฟล์ถูกก๊อปปี้ออกมาจริงครับ:

```

# สร้างโฟลเดอร์รับข้อมูล (ถ้ายังไม่มี)
mkdir -p ~/MT4_Backup

# ก๊อปปี้ GO Markets (ใช้ Path เต็มเพื่อเลี่ยงปัญหา Tilde)
cp -r "/home/weivo/.mt4/drive_c/Program Files (x86)/GO Markets MT4" ~/MT4_Backup/

# ก๊อปปี้ FP Markets
cp -r "/home/weivo/.mt4/drive_c/Program Files (x86)/FP Markets MT4 Terminal" ~/MT4_Backup/

```

**วิธีตรวจสอบ:** หลังจากรันเสร็จ ให้พิมพ์ `ls -l ~/MT4_Backup` ถ้าเห็นชื่อโฟลเดอร์ทั้งสองเจ้าปรากฏอยู่ แสดงว่า "รอดแล้ว" ครับ

---

### 2\. ล้างบ้านหลังเดิม (The Great Reset)

ในเมื่อเราได้ "หัวใจ" (โฟลเดอร์โปรแกรม) มาเก็บไว้ในที่ปลอดภัยแล้ว เราจะกำจัดความเละเทะของ `~/.mt4` ที่ไฟล์ระบบพัง (Error c0000135) ทิ้งไปครับ

```

# ปิด Wine ทั้งหมด
wineserver -k

# ลบ Prefix เดิมที่พังทิ้งไปเลย
rm -rf ~/.mt4

# สร้าง Prefix ใหม่ที่สะอาดและสมบูรณ์
WINEPREFIX=~/.mt4 wine wineboot -u

```

*(หากมีหน้าต่างถามหา Mono/Gecko ให้กด **Install** ทุกอันนะครับ เพื่อให้ Wine 11.0 ทำงานได้ครบถ้วนที่สุด)*

---

### 3\. ย้ายกลับและรันบน Openbox (โหมดอิสระ)

คราวนี้เราจะเอาไฟล์ที่เราสำรองไว้ กลับเข้าไปวางในบ้านหลังใหม่ที่แข็งแรงกว่าเดิมครับ:

1.  **สร้างโฟลเดอร์เป้าหมาย:**
    
    ```

    mkdir -p ~/.mt4/drive_c/"Program Files (x86)"
    
    ```

    
2.  **ย้ายโฟลเดอร์กลับเข้าที่:**
    
    ```

    cp -r ~/MT4_Backup/"GO Markets MT4" ~/.mt4/drive_c/"Program Files (x86)"/
    cp -r ~/MT4_Backup/"FP Markets MT4 Terminal" ~/.mt4/drive_c/"Program Files (x86)"/
    
    ```

    

---

### 4\. แก้ไขไฟล์ .desktop เพื่อรันแบบ Portable (ไม่ใช้ Virtual Desktop)

เข้าไปแก้ไขไฟล์ใน `~/.local/share/applications/` ทั้งสองไฟล์ (GO และ FP) ให้มีบรรทัด **Exec** ดังนี้ครับ:

-   **สำหรับ GO Markets:** `Exec=sh -c 'cd "/home/weivo/.mt4/drive_c/Program Files (x86)/GO Markets MT4" && WINEPREFIX=/home/weivo/.mt4 wine terminal.exe /portable'`
    
-   **สำหรับ FP Markets:** `Exec=sh -c 'cd "/home/weivo/.mt4/drive_c/Program Files (x86)/FP Markets MT4 Terminal" && WINEPREFIX=/home/weivo/.mt4 wine terminal.exe /portable'`
