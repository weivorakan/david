การลบโปรแกรมใน Ubuntu Server ให้ "เกลี้ยง" ที่สุดนั้น ไม่ใช่แค่การลบตัวโปรแกรมออกไปเฉยๆ แต่รวมถึงการตามไปเก็บกวาดไฟล์ตั้งค่า (Configuration files) และ Library อื่นๆ ที่พ่วงมาด้วยเพื่อให้ระบบสะอาดที่สุดครับ

คำแนะนำคือให้ใช้คำสั่งเรียงตามลำดับความสะอาด ดังนี้ครับ:

1. ลบโปรแกรมและไฟล์ตั้งค่า (Purge)
หากใช้ apt remove เฉยๆ ระบบจะเหลือไฟล์ Configuration ทิ้งไว้ เผื่อคุณอยากลงใหม่วันหลัง แต่ถ้าอยากให้เกลี้ยงต้องใช้ purge ครับ

Bash
sudo apt purge <ชื่อโปรแกรม>
2. ลบโปรแกรมพ่วงที่ไม่ได้ใช้แล้ว (Autoremove)
เวลาเราลงโปรแกรมหนึ่งอย่าง มักจะมีโปรแกรมเสริม (Dependencies) ถูกลงมาด้วยอัตโนมัติ เมื่อเราลบตัวหลักไปแล้ว ตัวเสริมเหล่านี้จะค้างอยู่ในเครื่อง คำสั่งนี้จะช่วยถอนรากถอนโคนพวกมันออกไปครับ

Bash
sudo apt autoremove --purge
Tip: การเติม --purge ต่อท้าย autoremove จะช่วยให้มั่นใจว่าไฟล์ตั้งค่าของโปรแกรมพ่วงเหล่านั้นจะถูกลบออกไปด้วย

3. ล้างไฟล์ขยะใน Cache (Clean)
Ubuntu จะเก็บไฟล์ติดตั้ง (.deb) ไว้ในเครื่อง เผื่อกรณีที่ต้องซ่อมแซมหรือลงซ้ำ ซึ่งกินพื้นที่พอสมควร คุณสามารถล้างมันออกได้ด้วยคำสั่ง:

Bash
sudo apt autoclean
สรุป: ท่าไม้ตายแบบบรรทัดเดียว
หากคุณต้องการลบแบบรวบยอดให้จบในคำสั่งเดียว (ลบโปรแกรม + ล้างไฟล์คอนฟิก + ล้างโปรแกรมพ่วง) ให้ใช้คำสั่งนี้ครับ:

Bash
sudo apt purge --auto-remove <ชื่อโปรแกรม>
ข้อควรระวัง:

ตรวจสอบรายชื่อก่อนกด Y: บางครั้ง autoremove อาจจะพยายามลบ Library ที่โปรแกรมอื่นยังจำเป็นต้องใช้ (แม้จะพบน้อยมาก) ควรเช็กรายชื่อโปรแกรมที่จะถูกลบก่อนยืนยันครับ

ไฟล์ใน Home Directory: คำสั่ง apt จะไม่ยุ่งกับไฟล์ในโฟลเดอร์ /home/user (เช่น ไฟล์ log หรือไฟล์ config เฉพาะส่วนตัวผู้ใช้) หากต้องการลบเกลี้ยงจริงๆ อาจจะต้องเข้าไปลบโฟลเดอร์ซ่อน (Hidden folders) ที่ชื่อ .ชื่อโปรแกรม ใน home directory ด้วยตัวเองครับ
