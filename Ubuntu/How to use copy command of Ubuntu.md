สำหรับการก๊อบปี้ไฟล์ทั้งหมดในโฟลเดอร์บน Ubuntu (หรือ Linux ค่ายอื่นๆ) คุณสามารถใช้คำสั่ง `cp` ผ่าน Terminal ได้หลายรูปแบบตามความต้องการครับ

---

### 1\. ก๊อบปี้เฉพาะ "ไฟล์" ทั้งหมดในโฟลเดอร์ปัจจุบัน

หากคุณต้องการก๊อบปี้ทุกไฟล์ในโฟลเดอร์ที่อยู่ตอนนี้ ไปยังโฟลเดอร์ปลายทาง:

```

cp * /path/to/destination/

```

-   `*` (Wildcard) หมายถึงทุกไฟล์
    
-   `/path/to/destination/` คือที่อยู่ของโฟลเดอร์ปลายทาง
    

### 2\. ก๊อบปี้ "ทั้งโฟลเดอร์" (รวมไฟล์และโฟลเดอร์ย่อย)

หากต้องการก๊อบปี้ทุกอย่าง รวมถึงโฟลเดอร์ที่ซ้อนอยู่ข้างในด้วย ต้องใช้ option `-r` (Recursive):

```

cp -r /path/to/source/* /path/to/destination/

```

### 3\. ก๊อบปี้แบบรักษาคุณสมบัติไฟล์ (แนะนำ)

ถ้าอยากให้ค่า Permission, วันเวลาที่สร้างไฟล์ (Timestamp) และความเป็นเจ้าของไฟล์เหมือนเดิมเป๊ะๆ ให้ใช้ `-a` (Archive):

```

cp -a /path/to/source/. /path/to/destination/

```

> **Tip:** การใช้ `.` (จุด) หลังโฟลเดอร์ต้นทาง จะช่วยให้ก๊อบปี้ **ไฟล์ที่ถูกซ่อน (Hidden files)** เช่น `.env` หรือ `.htaccess` ไปด้วย ซึ่งการใช้ `*` ปกติจะมองไม่เห็นไฟล์พวกนี้ครับ
---

### ตารางสรุป Option ที่ใช้บ่อย

| Option | คำอธิบาย |
| --- | --- |
| `-r` | ก๊อบปี้แบบรวมโฟลเดอร์ย่อย (Recursive) |
| `-v` | แสดงชื่อไฟล์ที่กำลังก๊อบปี้ให้เห็นบนหน้าจอ (Verbose) |
| `-i` | ถามยืนยันก่อนก๊อบปี้ทับไฟล์เดิมที่มีอยู่แล้ว (Interactive) |
| `-u` | ก๊อบปี้เฉพาะไฟล์ที่ใหม่กว่า หรือไฟล์ที่ยังไม่มีในปลายทาง (Update) |

**ข้อควรระวัง:** หากโฟลเดอร์ปลายทางต้องใช้สิทธิ์ Admin อย่าลืมพิมพ์ `sudo` ไว้หน้าคำสั่งด้วยนะครับ เช่น `sudo cp * /var/www/html/`
